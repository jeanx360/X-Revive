# Segurança e relatos

Para bugs comuns, use o modelo de issue. Para falhas que possam expor segredos ou
permitir escrita indevida em disco, não publique exploit ou dados pessoais numa
issue aberta. Use aviso privado de segurança do GitHub quando habilitado; caso
contrário, abra uma issue apenas pedindo canal privado, sem detalhes sensíveis.

Não anexe BIOS, MCPX, EEPROM, chaves de assinatura, credenciais FTP, IP público
ou discos completos. Logs em `X-Revive/diagnosticos/` não copiam firmware, mas
podem conter séries/modelos e dados de rede: revise antes de enviar.

A instalação limpa apaga o destino confirmado. Se o modelo exibido não for o
disco pretendido, cancele antes das confirmações. A beta não possui migração
preservando dados ou atualizador integral do sistema.
