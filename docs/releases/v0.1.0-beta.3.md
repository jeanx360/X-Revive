# X-Revive v0.1.0-beta.3 — candidata não publicada

Esta candidata foi retida durante a validação final: uma dependência da unidade
`console-eeprom.path` criava um ciclo de inicialização no systemd e podia impedir
a abertura da interface. A tag foi preservada para rastreabilidade; a IMG não foi
liberada publicamente. A correção segue na [beta.4](v0.1.0-beta.4.md).
