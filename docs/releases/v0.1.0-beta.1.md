# X-Revive v0.1.0-beta.1

Primeira beta pública dos fontes. Console em PC x86-64 UEFI com instalador
próprio, Xemu com integração de DVD, Rocky5 online ou ISO normalizada e firmware
do usuário. Base validada em teste físico em 24/10/2026.
[Guia](https://github.com/jeanx360/X-Revive/blob/main/docs/INSTALADOR-ONLINE.md),
[limitações](https://github.com/jeanx360/X-Revive/blob/main/docs/BETA.md).

## Conteúdo da prerelease

Fontes, patches, guias e catálogo de URLs/hashes. O GitHub gera os arquivos dos
fontes a partir da tag. Nenhuma IMG, ISO, BIOS, MCPX, EEPROM, animação proprietária
ou jogo é anexado nesta primeira publicação.

A IMG de bancada permanece local até concluir requisitos de distribuição dos
componentes. Identidade para rastrear testes, não um link de download ou promessa
de reprodução bit a bit:

| Item | Valor |
|---|---|
| Build | `20261024T163450Z-df48d0e06a6f` |
| Fingerprint local do build | `df48d0e06a6fbc3b4302ffa7d799155a7fd8456520702aad4f6e5e7775a832d7` |
| IMG | `console-xbox-installer.img`, 14.162.067.456 bytes |
| SHA256 IMG | `b192ae9418e8756a1a968389caffa3db1301ede209ed22c67dfd7b6c9c8a3a69` |
| SHA256 IMG.zst | `b0938a7a1500b427a172142f399d4510c906a0b54c64da65bbab46147fab74a0` |
| Kernel | `6.12.113+deb13-amd64` |
| NVIDIA | `550.163.01-2` |
| Xemu de fábrica | `0.8.138-xrevive-smc2` |

O fingerprint é um hash dos arquivos locais de entrada, **não um commit Git**.
Incluía assets privados antigos que não entram no sistema novo nem neste Git;
um clone público não tem os mesmos bytes de entrada. A tag identifica os fontes
públicos desta beta.

64 testes passaram na bancada original. A publicação verifica também um clone
sem arquivos privados; o teste UIX com pacote real é opcional. Instalação completa
e boot SSD passaram em VM. O relato físico não detalhou uma matriz nova completa.
Splash BIOS, Xbox físico, canal público e auditoria binária continuam pendentes.
